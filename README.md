# NASA Hackathon 2026

Preparation and project repository for NASA Space Apps Challenge 2026.

## Goal

Learn skills, explore NASA data, build prototypes, and create strong final project for NASA hackathon.

## Repository Structure

### `learning/`
Learning notes, tutorials, and practice materials.

### `python-projects/`
Python projects built during preparation.

### `arduino-projects/`
Arduino experiments, sensor projects, robotics, and prototypes.

### `nasa-data/`
NASA datasets, API experiments, data analysis, and space-related resources.

### `ideas/`
Hackathon problem ideas, brainstorming, research, and selected project concept.

### `team/`
Team roles, meetings, tasks, and collaboration notes.

### `final-project/`
Main hackathon project source code, assets, documentation, tests, and demo files.

### `presentation/`
Final presentation, speaker notes, screenshots, and demo material.

### `resources/`
Useful tutorials, documentation, tools, datasets, and references.
